# 恢复原则

自动快照位于 `backup_root/snapshots/<时间-标识>/payload`。恢复必须在 BDS 优雅停止、进程完全退出后进行。

1. 记录目标快照的 `manifest.json` 和校验值。
2. 对当前正式世界再做一次离线安全副本。
3. 将快照 payload 恢复到旁路暂存目录，不直接覆盖运行目录。
4. 校验 `db/CURRENT` 指向的 MANIFEST、`level.dat`、世界名、包绑定和所有权。
5. 原子交换暂存世界与正式世界，保留原世界用于回滚。
6. 启动 BDS，检查世界、模组栈、端口和日志，再由玩家实机验收。

不要在运行中的 LevelDB 上直接覆盖文件，也不要只复制单个 `.ldb` 文件尝试拼接世界。
